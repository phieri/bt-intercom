The workflow

  1. 01 / Pair

    Discover and pair headsets you own with scan and pair.

  2. 02 / Check

    Use status to confirm each headset exposes duplex audio in PipeWire.

  3. 03 / Talk

    Start run for full duplex, or map each headset's play/pause button with --ptt for press-and-hold transmission.

Requires BlueZ, PipeWire, WirePlumber, and compatible Bluetooth Classic headsets on a Linux system. Raspberry Pi is one supported platform. Browser playback is only a demonstration; audio stays on the host and its paired headsets.
